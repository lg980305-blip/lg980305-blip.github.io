05 / SETUP

Gemini 연결하기

아래 안내는 사이트 운영자를 위한 것입니다.

⚠ API 키를 HTML이나 JavaScript에 직접 넣지 마세요.
이 사이트는 GitHub Pages에서 동작하는 정적 사이트라 서버가 없습니다. 브라우저 코드에 넣은 키는 누구나 “페이지 소스 보기”로 확인할 수 있고, 도용되면 요금이 그대로 청구됩니다. 반드시 키를 보관할 중계 서버를 하나 두고, 이 페이지는 그 주소만 호출해야 합니다.

Vercel에 배포하는 경우 — 코드 수정이 전혀 필요 없습니다. 저장소를 Vercel로 배포하면 api/gemini.mjs가 같은 도메인에 함께 올라가고, 이 페이지가 자동으로 찾아 연결합니다.

  1. Google AI Studio에서 Gemini API 키를 발급받습니다.
  2. vercel.com/new 에서 이 저장소를 Import 하고 기본값 그대로 Deploy 합니다.
  3. Settings → Environment Variables 에 GEMINI_API_KEY 를 추가합니다.
  4. Deployments → 맨 위 항목 → Redeploy. 끝입니다.

Cloudflare Workers 를 쓰실 경우에는 도메인이 달라지므로, assets/ai.js 맨 위 ENDPOINT 에 워커 주소를 적어 주세요. 자세한 절차는 server/README.md 에 있습니다.

자세한 배포 절차와 명령어는 저장소의 server/README.md 에 단계별로 적어 두었습니다.
