03 — TECHNOLOGY

AI가 만드는 게 아니라,
무엇을 만들지 결정합니다.

외부 생성 AI는 콘텐츠를 만듭니다. 블랙홀맨브로스의 특허 기반 Character Evolution Engine은 사용자 반응을 분석해 다음 콘텐츠와 캐릭터·세계관이 어디로 진화해야 하는지 결정합니다.

HOW IT WORKS

반응이 다음 콘텐츠를 만듭니다.

콘텐츠가 배포되고 사용자 반응이 쌓이면, 그 데이터를 분석해 다음 진화 방향을 정하고 다시 콘텐츠 제작으로 연결합니다.

◉

02
⌁

04
▶

SYSTEM VALUE

AI Generation ≠ IP Evolution

생성 AI가 콘텐츠를 만드는 것과 IP가 어디로 진화할지 결정하는 것은 다른 문제입니다.

CHARACTER EVOLUTION ENGINE

Noise를 걷어내고,
Signal만 남깁니다.

단순한 인기 지표가 아니라 실제 IP 성장에 도움이 되는 패턴을 추출해 다음 콘텐츠 제작의 판단 기준으로 변환합니다.

Evolution Process

반응 데이터가 최종 진화 제안으로 바뀌는 4단계 처리 과정.

01
Noise Filtering불필요하거나 왜곡 가능성이 높은 데이터 제거
02
Signal Extraction반복적으로 나타나는 핵심 반응 정보 추출
03
Trend Detection캐릭터·감정·에피소드 유형별 선호 패턴 탐지
04
Evolution Recommendation다음 캐릭터·스토리·세계관 진화 방향 제안
